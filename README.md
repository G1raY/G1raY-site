# G1raY — landing page

Одностраничный сайт-визитка: кодинг, продажи и обучение продажам на FunPay, ресейл цифровых товаров.

Чистый HTML/CSS/JS, без сборки и зависимостей — просто открой `index.html` в браузере или задеплой как статику (GitHub Pages, Netlify, Cloudflare Pages и т.п.).

## Структура

- `index.html` — разметка
- `style.css` — фиолетово-чёрная тема, анимации, адаптивная вёрстка
- `script.js` — бургер-меню, появление блоков при скролле
- `assets/` — изображения
